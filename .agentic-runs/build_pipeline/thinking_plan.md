# Thinking Plan: Build Pipeline

## Architecture
The orchestrator is a single‑command Python script (`orchestrate_pipeline.py`) that executes the QRSPI pipeline phases sequentially using `subprocess`. Each phase is a deterministic harness tool located under the repository (`.agentic-pi/runtime`, `.agentic-pi/formal`, `.agentic-pi/validators`). The script:
1. Creates the run folder (`init_run.py`).
2. Compiles the raw user goal into a `goal_contract.json` (`compile_raw_goal.py`).
3. Generates candidate plans (`plan_router.py`).
4. Selects the best plan (`plan_selector.py`).
5. Merges the selected plan into `merged_plan.json` (`plan_merger.py`).
6. Executes the merged plan (`guarded_worker.py`).
7. Produces a verifier‑provenance artifact for the primary final output (`verifier_provenance.py`).
8. Runs formal verification on the final artifact (`harness_contract_verifier.py`).
9. Generates a keypair (if needed) and signs all artifacts (`harness_signing.py`).
10. Runs the policy engine and writes the final status (`certify_run.py`).

After each step the script validates that the expected files or directories exist before proceeding. Errors abort the pipeline with a clear message, ensuring deterministic execution.

## Design decisions
| Decision | Options | Chosen | Why |
|---|---|---|---|
| **Interpreter for subprocess** | `python` from PATH, `sys.executable`, shell `cmd` | `sys.executable` | Guarantees the same interpreter that runs the orchestrator (important on Windows where `python` may resolve to a different version). |
| **Repository root resolution** | `os.getcwd()`, environment variable, relative path from `__file__` | `Path(__file__).resolve().parents[3]` | The orchestrator lives in `.agentic-pi/runtime`; moving three levels up reliably reaches the repository root regardless of the current working directory. |
| **File existence validation** | Full schema validation, simple existence check, checksum verification | Simple existence check (`Path.is_file`/`is_dir`) | The heavy validation is performed later by `certify_run.py`; early checks keep the orchestrator lightweight and fast. |
| **Error handling** | Collect all errors and report at the end, abort on first failure, continue with warnings | Abort on first failure using `RuntimeError` | Guarantees a deterministic failure point; downstream phases would otherwise operate on incomplete state. |
| **Determine final output for verifier** | Hard‑code a path, ask user input, read from `goal_contract.json` | Read `goal_contract.json` and use the first entry of `final_outputs` | Keeps the orchestrator generic and driven by the contract, avoiding hard‑coded filenames. |
| **Signing strategy** | Sign only the final output, sign all artifacts, skip signing | Sign all artifacts (default behavior of `harness_signing.py` without a target) and then verify that a signature for the primary final output exists | Guarantees that every artifact is protected while still checking the critical final output. |
| **Logging** | Print to stdout only, write a log file, use `trace_logger` | Print concise status messages; detailed trace is handled by the individual tools | Simplicity for the orchestrator; detailed logs are already generated by the harness tools. |

## Step 1: .agentic-pi/runtime/orchestrate_pipeline.py

### Why
This is the only artifact the goal contract requires. The script implements the full pipeline, ensuring each phase runs in order, validates intermediate results, and aborts on error. It is the single‑command entry point for the user.

### Design
* Uses `argparse` to accept `--run-id` and `--goal`.
* Resolves the repository root from `__file__` to locate all harness scripts.
* Executes each phase via `subprocess.run` with `sys.executable` for interpreter consistency.
* After each phase, checks that the expected files/directories exist.
* Reads `goal_contract.json` to discover the primary final output for the verifier step.
* Generates a signing keypair if none exists and signs all artifacts.
* Finally runs `certify_run.py` and ensures `final_status.json` is produced.
* All functions have full docstrings, type hints, and no placeholders.

### Template
```python
#!/usr/bin/env python3
"""
Orchestrate the QRSPI pipeline for a single run.

The script executes the following phases in order:
1. init_run.py – creates the run folder.
2. compile_raw_goal.py – compiles the raw user goal into a goal contract.
3. plan_router.py – generates candidate plans (planner‑minimal agent).
4. plan_selector.py – selects the best plan.
5. plan_merger.py – merges the selected plan into merged_plan.json.
6. guarded_worker.py – executes the merged plan, producing artifacts.
7. verifier_provenance.py – creates a verifier provenance artifact for the final output.
8. harness_contract_verifier.py – runs formal verification on the final artifact.
9. harness_signing.py – generates a keypair (if needed) and signs artifacts.
10. certify_run.py – runs the policy engine and writes final_status.json.

Each step is invoked via subprocess, and the script validates that the expected
files exist before proceeding to the next phase. On any failure the script
exits with a non‑zero status and prints a helpful error message.
"""

import argparse
import json
import subprocess
import sys
from pathlib import Path
from typing import List


def _run_cmd(command: List[str], cwd: Path, description: str) -> subprocess.CompletedProcess:
    """Run a command in a subprocess, raising on failure.

    Args:
        command: List of command arguments (including interpreter).
        cwd: Working directory for the subprocess.
        description: Human‑readable description used in error messages.

    Returns:
        The CompletedProcess instance.

    Raises:
        RuntimeError: If the command exits with a non‑zero status.
    """
    try:
        result = subprocess.run(
            command,
            cwd=cwd,
            stdout=subprocess.PIPE,
            stderr=subprocess.STDOUT,
            text=True,
            check=False,
        )
    except Exception as exc:
        raise RuntimeError(f"{description} failed to start: {exc}") from exc

    if result.returncode != 0:
        raise RuntimeError(
            f"{description} exited with code {result.returncode}:\n{result.stdout}"
        )
    return result


def _ensure_file(path: Path, description: str) -> None:
    """Validate that a file exists, raising RuntimeError otherwise."""
    if not path.is_file():
        raise RuntimeError(f"{description} not found at {path}")


def _ensure_dir(path: Path, description: str) -> None:
    """Validate that a directory exists, raising RuntimeError otherwise."""
    if not path.is_dir():
        raise RuntimeError(f"{description} directory not found at {path}")


def main() -> int:
    parser = argparse.ArgumentParser(
        description="Run the full QRSPI pipeline for a single run."
    )
    parser.add_argument(
        "--run-id", required=True, help="Identifier for the run (e.g., my_run_001)"
    )
    parser.add_argument(
        "--goal",
        required=True,
        help="Raw user goal string that will be compiled into a contract",
    )
    args = parser.parse_args()

    run_id = args.run_id
    raw_goal = args.goal
    # Repository root is three levels up from this file (runtime/orchestrate_pipeline.py)
    repo_root = Path(__file__).resolve().parents[3]
    run_dir = repo_root / ".agentic-runs" / run_id

    # ----------------------------------------------------------------------
    # Phase 1 – init run
    # ----------------------------------------------------------------------
    init_cmd = [
        sys.executable,
        str(repo_root / ".agentic-pi" / "runtime" / "init_run.py"),
        "--run-id",
        run_id,
    ]
    _run_cmd(init_cmd, cwd=repo_root, description="Initialize run")
    _ensure_dir(run_dir, "Run folder")

    # ----------------------------------------------------------------------
    # Phase 2 – compile goal contract
    # ----------------------------------------------------------------------
    compile_cmd = [
        sys.executable,
        str(repo_root / ".agentic-pi" / "runtime" / "compile_raw_goal.py"),
        "--run-id",
        run_id,
        "--goal",
        raw_goal,
    ]
    _run_cmd(compile_cmd, cwd=repo_root, description="Compile goal contract")
    goal_contract_path = run_dir / "goal_contract.json"
    _ensure_file(goal_contract_path, "Goal contract")

    # ----------------------------------------------------------------------
    # Phase 3 – planner‑minimal agent (plan_router)
    # ----------------------------------------------------------------------
    planner_cmd = [
        sys.executable,
        str(repo_root / ".agentic-pi" / "runtime" / "plan_router.py"),
        "--run-id",
        run_id,
    ]
    _run_cmd(planner_cmd, cwd=repo_root, description="Generate planner plans")
    plans_dir = run_dir / "plans"
    _ensure_dir(plans_dir, "Plans directory")

    # ----------------------------------------------------------------------
    # Phase 4 – select best plan
    # ----------------------------------------------------------------------
    selector_cmd = [
        sys.executable,
        str(repo_root / ".agentic-pi" / "runtime" / "plan_selector.py"),
        "--run-id",
        run_id,
    ]
    _run_cmd(selector_cmd, cwd=repo_root, description="Select best plan")
    selected_plan = run_dir / "selected_plan.json"
    _ensure_file(selected_plan, "Selected plan")

    # ----------------------------------------------------------------------
    # Phase 5 – merge selected plan
    # ----------------------------------------------------------------------
    merger_cmd = [
        sys.executable,
        str(repo_root / ".agentic-pi" / "runtime" / "plan_merger.py"),
        "--run-id",
        run_id,
    ]
    _run_cmd(merger_cmd, cwd=repo_root, description="Merge plan")
    merged_plan = run_dir / "merged_plan.json"
    _ensure_file(merged_plan, "Merged plan")

    # ----------------------------------------------------------------------
    # Phase 6 – guarded worker (execute merged plan)
    # ----------------------------------------------------------------------
    worker_cmd = [
        sys.executable,
        str(repo_root / ".agentic-pi" / "runtime" / "guarded_worker.py"),
        "--run-id",
        run_id,
    ]
    _run_cmd(worker_cmd, cwd=repo_root, description="Execute merged plan")
    step_logs = run_dir / "step_logs"
    _ensure_dir(step_logs, "Step logs")

    # ----------------------------------------------------------------------
    # Phase 7 – verifier‑generator agent
    # ----------------------------------------------------------------------
    # Load the goal contract to discover the primary final output.
    try:
        goal_contract = json.loads(goal_contract_path.read_text(encoding="utf-8"))
        final_outputs = goal_contract.get("final_outputs", [])
        if not final_outputs:
            raise ValueError("final_outputs list is empty")
        primary_output = final_outputs[0]
    except Exception as exc:
        raise RuntimeError(f"Failed to read primary final output from goal_contract: {exc}") from exc

    verifier_cmd = [
        sys.executable,
        str(repo_root / ".agentic-pi" / "runtime" / "verifier_provenance.py"),
        "--run-id",
        run_id,
        "--artifact-id",
        "V.FINAL_OUTPUT",
        "--target",
        primary_output,
        "--source",
        "independent_verifier_agent",
        "--phase",
        "post_solution",
        "--kind",
        "verification",
    ]
    _run_cmd(verifier_cmd, cwd=repo_root, description="Generate verifier provenance")
    verifier_artifact = run_dir / "verifier_artifacts" / "V.FINAL_OUTPUT.json"
    _ensure_file(verifier_artifact, "Verifier provenance artifact")

    # ----------------------------------------------------------------------
    # Phase 8 – formal verification
    # ----------------------------------------------------------------------
    formal_cmd = [
        sys.executable,
        str(
            repo_root
            / ".agentic-pi"
            / "formal"
            / "harness_contract_verifier.py"
        ),
        str(run_dir),
        primary_output,
    ]
    _run_cmd(formal_cmd, cwd=repo_root, description="Run formal verification")
    formal_artifact = run_dir / "verifier_artifacts" / f"F_{run_id.upper()}.json"
    _ensure_file(formal_artifact, "Formal verification artifact")

    # ----------------------------------------------------------------------
    # Phase 9 – cryptographic signing
    # ----------------------------------------------------------------------
    signing_script = str(
        repo_root
        / ".agentic-pi"
        / "formal"
        / "harness_signing.py"
    )
    # Generate a keypair if none exists.
    keygen_cmd = [sys.executable, signing_script, "keygen", str(run_dir)]
    _run_cmd(keygen_cmd, cwd=repo_root, description="Generate signing keypair")
    # Sign all artifacts (the tool signs everything when no target is given).
    sign_cmd = [sys.executable, signing_script, "sign", str(run_dir)]
    _run_cmd(sign_cmd, cwd=repo_root, description="Sign artifacts")
    # Verify that a signature for the primary final output exists.
    sig_path = run_dir / f"{primary_output}.sig"
    _ensure_file(sig_path, "Signature for primary final output")

    # ----------------------------------------------------------------------
    # Phase 10 – certify run (policy engine)
    # ----------------------------------------------------------------------
    certify_cmd = [
        sys.executable,
        str(
            repo_root
            / ".agentic-pi"
            / "validators"
            / "certify_run.py"
        ),
        str(run_dir),
    ]
    _run_cmd(certify_cmd, cwd=repo_root, description="Run certification")
    final_status = run_dir / "final_status.json"
    _ensure_file(final_status, "Final status")

    print(f"Pipeline completed successfully for run_id={run_id}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
### Validation
The script will be executed by the test harness. Validation steps include:
- `init_run.py` creates `.agentic-runs/<run_id>`.
- `compile_raw_goal.py` creates `goal_contract.json`.
- `plan_router.py` creates the `plans/` directory.
- `plan_selector.py` creates `selected_plan.json`.
- `plan_merger.py` creates `merged_plan.json`.
- `guarded_worker.py` creates `step_logs/` and any artifacts defined by the plan.
- `verifier_provenance.py` creates a verifier artifact in `verifier_artifacts/`.
- `harness_contract_verifier.py` creates `F_<RUN_ID>.json`.
- `harness_signing.py` creates a keypair and `.sig` files for artifacts.
- `certify_run.py` creates `final_status.json` and `certification.json`.
If any of these files are missing, the script aborts with a clear error.
