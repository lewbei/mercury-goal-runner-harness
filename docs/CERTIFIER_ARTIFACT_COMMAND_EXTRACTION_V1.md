# Certifier Artifact Command Extraction V1

## Overview

This document describes the certifier artifact command extraction.

## behavior-preserving helper extraction

The certifier uses behavior-preserving helper extraction to maintain compatibility.

## certifier_artifact_commands.py

The `certifier_artifact_commands.py` module handles artifact command extraction.

## log_artifact_test_verifier

The `log_artifact_test_verifier` function logs artifact test verification.

## does not move

The extraction does not move existing functionality.

Commands use `python <run-relative-script.py> [safe args]` format.
