**Tweet 2 (reply):**
The harness follows a QRSPI pipeline:
INTAKE → RESEARCHING → DESIGNING → STRUCTURING → PLANNING
→ IMPLEMENTING → VALIDATING → CERTIFYING → DONE

Each phase produces artifacts. The certifier verifies all artifacts before certifying DONE.

**Tweet 3 (reply):**
Why I built this:

I noticed AI coding agents often claim "DONE" without proper verification. So I built a system that:

1. Verifies at multiple levels (planning, step, final)
2. Provides deterministic status
3. Works with any agent
